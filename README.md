# Coinzy Mobile Application - Manual Testing Project

## Project Overview

This project contains manual testing activities performed on the Coinzy mobile application.

The objective of this assignment was to validate the core functionality of the application, identify defects, and ensure a smooth user experience through manual and exploratory testing.

---

## Project Objective

To test the main features and functionality of the Coinzy mobile application using manual testing techniques.

---

## Scope

### Included Modules

* Signup
* Login
* Coin Identification
* Navigation
* Guest Access

### Excluded Modules

* Performance Testing
* Security Testing
* Load Testing

---

## Testing Types Performed

* Functional Testing
* UI Testing
* Usability Testing
* Validation Testing
* Exploratory Testing

---

## Test Approach

Manual testing was performed on Android devices to validate the application's core user flows and identify functional defects.

The testing focused on:

* User registration
* User login
* Coin identification functionality
* Application navigation
* Guest user access
